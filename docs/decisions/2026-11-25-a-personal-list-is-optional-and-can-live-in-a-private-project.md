# A personal list is optional, and can live in a private project

Question: Must a person keep a personal list, and what does a person with no to-do tool get?

A personal list is never required to use playbook. A person with a to-do tool uses it. A person with none who wants a list of their own gets one in a small private project that belongs only to them. A person who wants no list has no personal tracker, and every skill behaves as before.

## What was decided

1. Never required. Setup offers a list of their own only when the person wants one. With no list, every skill behaves as it did before personal trackers existed.
2. A to-do tool the person already uses becomes their personal tracker.
3. With no tool, setup makes a small private project that belongs only to the person, through the `new` skill. Their list lives there in the markdown tracker, one file per item.
4. With no account on a code host, that project stays on the person's own computer, with no remote.
5. With a remote, the skills commit and push after each change to the list, and pull before reading it.

## Options considered

- A personal list offered only to people who already have a to-do tool: not taken. A person with no tool may want a simple list most.
- A personal list kept as files in a shared project: not taken. Others could read it.
- A private project of the person's own: taken.

## What settled it

- The person's ruling that a list is never required and that no one is pushed toward a tool.
- The glossary: a personal tracker is seen only by the person.

## Not settled here

- How the questions the `new` skill asks, such as a scope, are shortened for a private list.
